4. 输入、数据表示与输出契约

4.1 拟合输入

四份输入都必须包含名为 Pwa 的 TTree，七个分支均为 Double_t[4]，顺序是 [px,py,pz,E]：

p4_pip1  p4_pim1  p4_pi01
p4_pip2  p4_pim2  p4_pi02  p4_gam
树名和分支名是集中硬编码的，不是命令行参数。GVVBranchConfig 提供默认值，Fit.cu 又在“User input contract”块显式设置一次；PostFit 使用默认构造。若输入生产改变命名，应同步修改该配置，而不是改 GPU 内核。src/GVVSample.cu:25–31; src/Fit.cu:507–516; src/PostFit.cu:831–833

粒子 1/2 的三 pion 分组被直接当作 ω1/ω2；程序不枚举其它三 pion 配对，也不在振幅级做配对相干和。绘图时才对全同 ω 标签做交换对称化。

4.2 四份样本分别做什么

文件用途进入目标函数的方式
data.root选择后的候选事例(+\sum_d\log P(x_d))
normalization_mc.rootψ(2S)→γ6π PHSP，经与数据相同选择；数值归一化积分(N(\theta)=N_{MC}^{-1}\sum_m I(x_m;\theta))
SB1.root二维 sideband 第一层(-0.5\sum\log P)
SB2.root二维 sideband 重叠修正(+0.25\sum\log P)

这是“在似然中带符号扣除背景”，没有多项式或其它显式背景 PDF。include/NLL_estimator.h:26–33; src/NLL_estimator.cu:437–481

4.3 拟合输出

  • fit_result-initial.txt：最佳解、收敛元数据、参数/误差、耦合、固定质量宽度与 Flatté 参数。
  • Cova_matrix.dat：按 fit parameter 顺序写出的 (12\times12) 协方差矩阵。
  • projection0.root：MC、data、bg、component_map、metadata 五棵树；MC 含总权重、0++/0-+ 权重及 15×15 分量/干涉权重。
  • runlog/gpujob-%j.out：所有起点的完整 Minuit 过程；只有最佳解写正式结果。

projection 中的背景绘图权重是似然系数的相反数，即 SB1 (+0.5)、SB2 (-0.25)，这样“signal MC + background estimate”可直接与 data 比较。src/NLL_estimator.cu:806–824

6. 从张量到最终 |A|²：代码如何计算

6.1 ω→3π 电流

每个 ω 的电流拆成实几何四矢量与复动力学因子：

\[ \Omega^\mu=E^\mu(f_{12}^{(\rho)}+f_{10}^{(\rho)}+f_{20}^{(\rho)}),\qquad E^\mu=\epsilon^\mu{}_{\nu\lambda\sigma}p_+^\nu p_-^\lambda p_0^\sigma . \]

omega_geometric_current 显式四重循环并乘三个降指标度规符号；rho_isobar_factor 计算两个顶点的 (B_1)、ρ 的 P-wave BWR，然后 build_omega_decay_current 将三种 ρ 配对相干相加。include/Omega.h:43–80, 82–148

6.2 纯轨道张量和分波

tensor::Gwavetide 构造 (~g_{\mu\nu}=g_{\mu\nu}-p_\mu p_\nu/p^2)；Projection_Pwave 得到横向 (\tilde r_\mu)；Projection_Dwave 得到对称无迹 (\tilde r_\mu\tilde r_\nu-\tfrac13\tilde g_{\mu\nu}(\tilde r\cdot r))。gvv_orbital_t1/t2 再分别把 (B_1/B_2) 包进张量。include/Tensor.h:102–122; include/GVVAmplitude.h:90–121

当前活动模型只用：

\[ \widehat U_{00}^{\mu\nu}=g^{\mu\nu}E_1^\alpha E_{2\alpha}, \] \[ \widehat U_{11}^{\mu\nu}=\epsilon^{\mu\nu\rho\sigma}p_{\psi\rho}p_{\gamma\sigma}B_1(Q_{\psi\gamma X}) \left[\epsilon^{\delta\lambda}{}_{\alpha\beta}K_\lambda E_1^\alpha E_2^\beta\tilde t^{(1)}_\delta\right]. \]

gvv_scalar_22_tensor 和含 (B_2) 的 D 波仍保留为可复用骨架，但当前 7 个 term 没有任何 22 项。include/GVVAmplitude.h:123–190; include/GVVModel.h:186–207

6.3 F-matrix 的含义

(F_{ab}) 不是额外传播子，也不是拟合参数；它是两个张量基底在初末态极化求和后的实运动学双线性：

\[ F_{ab}(x)=-\frac12\sum_{\mu=1,2}\sum_{\nu\nu'} U_a^{\mu\nu}g_{\nu\nu}\,P_{\gamma}^{\nu\nu'}\,g_{\nu'\nu'}U_b^{\mu\nu'} . \]

它只依赖事例四动量，所以每个样本在 Prepare() 时由 CalGVVFmatrix_device 一次计算 3×3 并缓存；Minuit 每一步不重算张量缩并。include/GVVAmplitude.h:192–245; src/kernel.cu:45–78; src/GVVSample.cu:118–152

6.4 最终确实是振幅模平方

每一项先形成复系数

\[ z_i(x)=\Lambda_i f_{X_i}(K^2)f_{\rho,1}f_{\rho,2}f_\omega(k_1^2)f_\omega(k_2^2), \]

再计算

\[ I(x)=\sum_{ij}\operatorname{Re}\left[z_i z_j^*F_{w_iw_j}(x)\right]=\sum_{\rm pol}|\mathcal A(x)|^2. \]

CalGVVPDF_device 的双重 term 循环就是这一步，结果写入每事例 amp2。传播子与张量在实现上已分离：F 缓存负责张量/极化，gvv_x_propagator 和 ω 宽度表负责动力学，最后才相乘。src/kernel.cu:80–133; include/GVVAmplitude.h:262–325

7. 一次拟合从头到尾发生什么

  1. Fit.cu::main 解析四个 ROOT、输出名、起点数和种子，创建集中分支配置。
  2. NLL_estimator 加载 data、normalization MC、SB1、SB2；GVVSample::Load 检查树/分支/非空条目并复制到 host 连续数组。
  3. Prepare 构建 ω 三体跑宽表、上传模型，为所有样本分配 unified memory 并缓存 F。
  4. 起点 0 用 nominal；后续起点只随机复耦合的模和相位，物理传播子参数保持 nominal 起点。
  5. Minuit FCN 调用 apply_gvv_fit_parameters，再调用负的有效 log likelihood。每次先用 normalization MC 求平均强度，再处理 data 和带符号 sideband。
  6. 每个起点依次 MIGRAD(最多 20000 calls)、HESSE；只有 MIGRAD/HESSE=0、covariance≥2、有限 NLL/EDM 且 EDM≤(10^{-3}) 才算可选。
  7. 按最低 NLL 选最佳；并列时优先 covariance status、较小 EDM、较早 start。
  8. 只为最佳解写文本、协方差和 projection；所有起点只留在 batch log。

src/Fit.cu:235–327, 459–607; include/Minuit.h:11–65; src/NLL_estimator.cu:391–481

似然归一化：normalization 是 accepted PHSP MC 上强度的算术平均，而不是事例数归一化后的任意常数。每个样本的 PDF 为 intensity / normalization。若强度、PDF 或归一化非正/非有限，该点被返回为极差似然而被 Minuit 排斥。

8. truth MC 与 PostFit

truth_mc.root 应来自与 normalization_mc.root 同一批 PHSP 生成：truth 保存全部生成事例，normalization 保存通过数据同样选择的子样本；两者均使用相同 Pwa 和七分支结构。Fit 不需要 truth，PostFit 才需要。

GVVPostFitEvaluator 对 truth 和 selected 各算一次紧凑上三角分量矩阵（7 个对角 + 21 个两两干涉）。随后：

\[ FF_i=I_i^{truth}/I_{tot}^{truth},\quad IF_{ij}=I_{ij}^{truth}/I_{tot}^{truth},\quad \epsilon_i=I_i^{sel}/I_i^{truth},\quad \epsilon_{tot}=I_{tot}^{sel}/I_{tot}^{truth}. \]

误差不是只看对角参数误差，而是对 12 个参数做有界中心/单边有限差分，构造 Jacobian (J)，再算 (V_{obs}=JV_{fit}J^T)。输入协方差必须有限、对称且 Cholesky 正定。src/PostFit.cu:120–296, 298–516, 795–870; src/GVVFitParameters.cu:329–405

ROOT 输出的 observables 树保存 category/name/value/error/truth_integral/selected_integral，另写 observable covariance/correlation 和 closure metadata；文本适合检查，LaTeX 适合文章表格。

9. projection 与角矩绘图

主图的六变量为：(M(\omega\omega))、合并的 (M(\gamma\omega))、(cos\theta_\gamma)、交换对称的 (cos\theta_\omega)、合并的两个 ω 衰变面方位角、交换对称的衰变面 (Δφ)。详细图另加合并的 (M(3\pi))。include/GVVPlotUtils.h:28–68, 176–202

BuildPanel 用 data 单位权重、bg 的 weight_bg、MC 的 fitted weight 构图；总期望=signal MC+background。主图画 coherent 0++/0-+，component 图只画七个 |Ai|² 对角项，故这些曲线因缺少干涉而不必相加等于总线。include/GVVPlotUtils.h:280–348, 411–511

偶阶 (P_0,P_2,P_4,P_6) 使用 ω 交换对称化，可作物理比较；奇阶 (P_1,P_3,P_5) 使用输入标签的 ω1，只诊断组合/排序偏置。include/GVVAngularMoments.h:52–203

13. 当前应特别知道的限制、故障模式和扩展点

  1. 发行闭环：Release 的物理源码与已跑通基线一致，但目录重构后的 worker 仍需用一次新 JobID 做 GPU 端到端验证，确认 parameter rows、projection 和协方差来自同一作业。
  2. PostFit 尚缺数据：没有 truth MC 就不能给出效率和 truth-phase-space fit fraction；不能用 normalization MC 自己代替 truth。
  3. 默认计算量：scripts/Sub.sh 默认运行 10 个起点；烟雾测试应显式传 1，正式拟合可使用默认或显式指定。
  4. 输出会同名覆盖：按既定策略，fit_result-initial.txt、Cova_matrix.dat、projection0.root 会被新作业覆盖；图件集中在 results/plot/，不会与数值结果混放。
  5. 分支不是运行时配置：输入命名变化需改 GVVBranchConfig/Fit 配置并重编译。
  6. F 缓存的代价：每事例 9 doubles，另有七套四动量和强度；大 truth 样本的 PostFit 还分配每事例 28 个 component doubles，GPU/统一内存需要按事例数评估。
  7. 张量数值测试仍可加强：现在测试主要是公式局部断言和 device 编译；建议未来增加洛伦兹/交换对称性、F 对称性与非负强度的固定事例数值回归。
  8. 物理质量：程序收敛和 closure 只证明数值链自洽，不证明模型充分；后续仍需结合投影、角矩、系统学和替代模型判断物理充分性。

扩展新共振的最短代码路径

若新态复用现有 00 或 11 张量：在 GVVModel.h 增 resonance/term 枚举、默认参数、名称和映射；参数顺序会由 GVVFitParameters 自动按 term 生成，但必须同步 component 容量、绘图 pretty name 和测试。若是新 (J^{PC})，还需在 GVVAmplitude.h 增基底、在 F 维度和 kernel 中同步。改变 ω 衰变模型则主要改 Omega.h 与 OmegaPropagator.cu，生产张量可保持分离。

14. 接手项目时的完整重建检查表

1. 确认 RootSet 四文件满足 Pwa/七分支/[px,py,pz,E] 2. make -j4 all tests，并运行四个 tests + PostFit --self-test 3. ./scripts/Sub.sh 1 20260815 做当前二进制烟雾拟合（默认不传参数是 10 起点） 4. 用 sacct + runlog 同时确认 scheduler success、Minuit status、EDM、covariance、boundary 5. 核对 fit_result、Cova_matrix、projection0.root 时间戳和同一 JobID 6. ./scripts/draw.sh，检查 results/plot 下的 3×2、详细图、components、even/odd moments 7. truth MC 到位后 ./scripts/Sub_postfit.sh 8. 检查 fraction/group/component closure，再引用 FF、干涉、效率 9. 任何新物理项同时更新 model、参数布局、绘图映射、测试和项目日志

按这一顺序，读者可以从一个 ROOT 事例追踪到 ω 电流、协变张量、F 矩阵、复传播子、|A|²、有效似然、Minuit 最佳解、投影权重以及 truth-level 后处理；发行副本只保留这条活动 GVV 链。
